ANTOINE PIERRARD - PORTFOLIO

To view the website locally:
1. Extract the ZIP archive.
2. Open index.html in a modern web browser.

To publish it elsewhere, upload the complete folder without changing its
internal structure. The assets and downloadable documents use relative paths.

Main files:
- index.html: page content
- styles.css: visual design and responsive layout
- script.js: interactions and animations
- assets/: images and project visuals
- downloads/: CV, reports and presentations
